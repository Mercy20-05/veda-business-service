# Veda Technology - Business & Services Website

A multi-section business website built with modern HTML5, CSS3, and Vanilla JavaScript for **Veda Technology**[cite: 1]. The site highlights the company's IT solutions, technical training tracks, internship pathways, and enterprise services[cite: 1].

---

## 1. Project Overview

- **Organization**: Veda Technology[cite: 1]
- **Deliverables**: Responsive multi-section website (`index.html`, `styles.css`, `script.js`, `README.md`)[cite: 1]
- **Core Technology Stack**: HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript (ES6+), Git/GitHub[cite: 1]

---

## 2. Approach & Architecture

### A. Semantic & Accessible Markup (HTML5)
- **Document Structure**: Leveraged semantic tags (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`) to promote search indexability and screen-reader accessibility[cite: 1].
- **SEO Elements**: Standard metadata configurations including descriptive `<title>`, search descriptions, viewport optimization tags, and hierarchical heading distribution (`h1` through `h4`)[cite: 1].

### B. Scalable, Responsive Styling (CSS3)
- **Design Tokens**: Standardized color palettes, typography variables, box shadows, and transitions configured via CSS Custom Properties (`:root`).
- **Responsive Layouts**: Constructed with CSS Grid and Flexbox to ensure fluidity across desktop displays, tablets, and small-screen mobile viewports[cite: 1].
- **Component Reusability**: Uniform card modules (`.card`), badges (`.pill`, `.badge`), and interaction-ready buttons (`.btn`).

### C. Lightweight Vanilla Interactivity (JavaScript)
- **Responsive Menu Toggle**: Provides a clean hamburger interaction for mobile devices[cite: 1].
- **Smooth Navigation & ScrollSpy**: Connects active menu highlights dynamically using modern `IntersectionObserver` bindings.
- **Accordion Logic**: Accessible FAQ collapse/expand animations tracking internal container scroll heights[cite: 1].
- **Form Validation & Feedback**: Intercepts contact requests, validates essential inputs, and renders visual confirmation messaging[cite: 1].

## 5. Local Setup & Usage

1. Clone or download the repository to your local workspace.
2. Ensure `index.html`, `styles.css`, and `script.js` are in the same folder.
3. Open `index.html` directly in any modern browser, or run a local dev server (e.g., VS Code *Live Server*).
